# practice

练习 / 示例代码仓库。每个独立主题放在单独的文件夹中以作区分。

## 模块

| 目录 | 说明 |
|------|------|
| [`generic-invoke`](./generic-invoke) | 统一泛化调用骨架：同一 Nacos 注册中心下，两个独立部署的系统之间「按接口名 + 入参」直连调用（不走 Gateway）。接口地址配置在 DB 表中。 |
| [`opencode-dep`](./opencode-dep) | 基于 opencode + oh-my-openagent + superpowers + OpenSpec 的端到端 AI 研发工作流（立项→需求→设计→计划→编码TDD→测试→审查→CI→归档→发布）配置/使用教程、可叠加的 Skills/MCP/插件清单，以及可运行 demo。 |
